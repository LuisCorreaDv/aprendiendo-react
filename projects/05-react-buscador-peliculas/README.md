## Buscador de peliculas con React

El proyecto es crear una aplicación para buscar películas

API a usar: 

- https://www.omdbapi.com/
- API_KEY: 

Requerimientos: 

- Necesita mostrar un input para buscar la película y un botón para buscar
- Lista de películas encontradas y muestra el título, año y poster.
- Hacer que las películas se muestren en un grid responsive 

Primera iteración: 

- Evitar que se haga la misma búsqueda dos veces seguidas.
- Hacer que la búsqueda se haga automáticamente al escribir.
- Evitar que se haga la búsqueda continuamente al escribir (debounce).
